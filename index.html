About me

the human behind the test cases

I’m an Associate QA Engineer with hands-on experience testing web and mobile applications. I design and run test cases across functional, regression, integration and UI testing, and I follow defects through their full lifecycle in JIRA until they’re truly fixed.

On the automation side, I write Selenium scripts in Python using the Page Object Model and test mobile apps with Appium. I also wear a second hat as Scrum Master, keeping our sprints, stand-ups and retros running smoothly.

I care about the small details users notice, and I’m always learning new QA tools and practices.
